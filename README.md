# dawg-replay

dawg-replay запускает на вашем компьютере скрипты сбора данных: карточки товаров с маркетплейса, цены, объявления, статистику. Скрипты работают через облачные браузеры DAWG, локальный браузер не нужен.

Скрипт пишет кодинг-агент (Claude Code или Codex) со скиллом dawg-replay-builder. Вы описываете задачу словами, агент один раз проходит нужный путь по сайту в браузере DAWG и собирает из него обычный скрипт с параметрами. Скрипт попадает в приложение, и дальше вы запускаете его сами: в веб-интерфейсе меняете параметры, смотрите прогресс и скачиваете результат. Агент снова нужен, только когда сайт поменялся и скрипт пора чинить.

Приложение для клиентов DAWG, которым нужны регулярные выгрузки с сайтов. Читать код не обязательно. Нужны ключ DAWG и Claude Code или Codex, работает на macOS, Windows и Linux. Скрипт запускается без агента, расход только в минутах браузеров DAWG по тарифу.

## Установка

1. Поставьте `uv`, он устанавливает приложение и запускает скрипты: https://docs.astral.sh/uv/getting-started/installation/

   macOS и Linux:

   ```sh
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

   Windows (PowerShell):

   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```

   После установки откройте новое окно терминала. Python ставить отдельно не нужно, uv скачает его сам.

2. Поставьте приложение:

   ```sh
   uv tool install dawg-replay
   ```

   Проверка:

   ```sh
   dawg-replay --version
   ```

   Если команда не найдена, выполните `uv tool update-shell` и откройте терминал заново.

3. Сохраните ключ DAWG. Ключ выдаётся в личном кабинете https://dawgswarm.ru.

   ```sh
   dawg-replay config set-key
   ```

   Команда спросит ключ и положит его в системное хранилище паролей (Связка ключей на macOS, Диспетчер учётных данных на Windows, Secret Service на Linux). Ключ можно и вставить из буфера: `pbpaste | dawg-replay config set-key` на macOS. Другой способ: откройте интерфейс командой `dawg-replay ui` и введите ключ на экране «Настройки», там же есть кнопка проверки.

## Подключение агента

Агенту нужен скилл dawg-replay-builder и сервер dawg-mcp, через который он открывает браузер DAWG. Оба ставятся одним плагином.

### Claude Code

В сессии Claude Code:

```
/plugin marketplace add dawgswarm/dawg-replay-builder
/plugin install dawg-replay-builder@dawg-replay
```

При установке плагин спросит ключ DAWG и сохранит его в системном хранилище паролей. Проверка: `/mcp` показывает сервер `dawg` в статусе connected.

### Codex

Для Codex скилл копируется в каталог скиллов, а dawg-mcp прописывается в `~/.codex/config.toml`. Пошагово: [README плагина](https://github.com/dawgswarm/dawg-replay-builder#codex).

## Первый скрипт

Заведите одну папку для работы с агентом и открывайте агента в ней:

```sh
mkdir -p ~/dawg-scripts
cd ~/dawg-scripts
claude
```

Для Codex вместо `claude` запустите `codex`. Опишите задачу своими словами, например:

> Собери карточки с Ozon по поисковому запросу: название, цена, рейтинг и число отзывов. Запрос и число страниц хочу менять между запусками. Результат в CSV.

Дальше агент:

1. Уточнит, что собирать, что вы будете менять между запусками (это станут параметры) и куда отдавать данные.
2. Пройдёт путь по сайту в облачном браузере DAWG. На это уходит немного минут тарифа.
3. Напишет скрипт в `~/dawg-scripts/<имя>/script.py` и прогонит его на маленьких параметрах, пока прогон не пройдёт.
4. Зарегистрирует скрипт в приложении (`dawg-replay add`) и скажет, как он называется.

После этого скрипт виден в интерфейсе на экране «Скрипты». Черновик в `~/dawg-scripts` можно оставить для будущих правок: у приложения своя копия.

## Работа в интерфейсе

```sh
dawg-replay ui
```

Команда запускает интерфейс на этом компьютере и открывает его в браузере. Окно терминала держите открытым: пока работает команда, работает интерфейс. Остановить: Ctrl+C. Запуски, начатые в интерфейсе, при остановке отменяются.

- Главная. Что идёт сейчас, что требует внимания (последний запуск упал или собрал не всё), последние запуски, быстрый запуск по пресетам и остаток минут.
- Скрипты. Библиотека скриптов с поиском. На карточке скрипта форма параметров, пресеты, история запусков, версии и код для просмотра.
- Запуск. Выберите скрипт, поменяйте параметры и нажмите «Запустить». Сохраните удачный набор параметров как пресет, чтобы запускать его одной кнопкой. На экране запуска видны шаги, прогресс, собранные строки и журнал; кнопка «Отменить» останавливает запуск и закрывает его браузеры.
- Результаты. Файлы, которые сохранил скрипт, появляются на экране запуска с кнопкой «Скачать». «Открыть папку» показывает их в файловом менеджере. Старые запуски доступны из истории скрипта.
- Импорт. Если агент работал на другом компьютере или прислал файл, на экране «Скрипты» нажмите «Добавить скрипт» и перетащите `script.py`. Приложение проверит файл и покажет, что будет добавлено, а для новой версии и отличия от текущей.
- Настройки. Ключ DAWG, лимит одновременных запусков и предел длительности запуска.

Те же действия есть в терминале, например:

```sh
dawg-replay list                                  # скрипты
dawg-replay run ozon-search-cards --set query="кофемолка" --follow
dawg-replay runs                                  # история запусков
dawg-replay usage                                 # минуты браузеров за 7 дней по скриптам
```

Минуты в `usage`, на экране запуска и на странице скрипта примерные: они считаются по событиям запусков. Точный расход и остаток показывает главная, данные приходят из личного кабинета DAWG.

Справка по любой команде: `dawg-replay <команда> --help`.

## Когда скрипт сломался

Сайты меняются, и скрипт, который работал вчера, может упасть. Упавший запуск попадает в блок «Требует внимания» на главной. На экране запуска видна причина: сообщение скрипта или последние строки его вывода.

Попросите агента починить скрипт, в той же папке `~/dawg-scripts`:

> Скрипт ozon-search-cards упал, запуск 20261114-091500-a1b2c3. Почини.

Номер запуска есть на его экране и в `dawg-replay runs`. Агент прочитает журнал, заново пройдёт проблемное место и зарегистрирует новую версию. Старые версии сохраняются: если новая чем-то хуже, на карточке скрипта в блоке «Версии» сделайте текущей прежнюю.

Если на главной появился блок «Возможно, остался браузер», запуск остановился в момент создания браузера. Нажмите «Освободить» у браузеров, которые вы не открывали сами: открытый браузер тратит минуты.

## Регулярные запуски

Приложение ставит регулярный запуск в планировщик системы: cron на macOS и Linux, Планировщик задач на Windows. Своей службы у приложения нет, `dawg-replay ui` держать открытым не нужно. Запуск идёт по пресету, поэтому сначала сохраните пресет с нужными параметрами в форме запуска или командой:

```sh
dawg-replay preset save ozon-search-cards daily --set query="кофемолка" --set max_pages=3
```

В интерфейсе: на странице скрипта блок «Регулярный запуск». Выберите пресет и как часто запускать (каждый день, раз в неделю, каждые несколько часов) и нажмите «Добавить расписание». Ближайшие запуски видны на главной в блоке «По расписанию», а сами запуски в истории помечены «по расписанию».

То же в терминале:

```sh
dawg-replay schedule add ozon-search-cards --preset daily --daily 09:00
dawg-replay schedule add ozon-search-cards --preset daily --weekly пн 09:00
dawg-replay schedule add ozon-search-cards --preset daily --every-hours 6
dawg-replay schedule list                 # расписания, ближайший запуск, есть ли задача в планировщике
dawg-replay schedule remove <id>          # снять
```

`--every-hours` принимает 1, 2, 3, 4, 6, 8 или 12 и считает от полуночи: при 6 запуски в 0:00, 6:00, 12:00 и 18:00. На macOS и Linux есть ещё `--cron "30 9 * * 1-5"` для своего выражения cron. Время местное.

Что ставится в планировщик: полный путь к `dawg-replay` и каталог `uv` в `PATH` (у cron и Планировщика свой короткий `PATH`), команда `dawg-replay run <скрипт> --preset <пресет> --follow --schedule <id>` и вывод в лог `schedules/<id>.log` в [каталоге данных](#где-лежат-данные). В crontab своя строка помечена `# dawg-replay:<id>`, остальные строки приложение не меняет. На Windows задачи лежат в папке `dawg-replay` Планировщика заданий.

`schedule list` сверяет расписания с планировщиком. Если задачу удалили вручную, напротив расписания будет «задача пропала»; если в планировщике осталась задача без расписания в приложении, она показана отдельно и сама ничего не запустит. `dawg-replay schedule sync` ставит пропавшие задачи заново и снимает лишние.

При удалении скрипта или пресета его регулярные запуски снимаются вместе с ним.

Ключ DAWG берётся из системного хранилища паролей, поэтому компьютер должен быть включён, а пользователь должен быть в системе. На Linux без графического сеанса хранилище паролей может быть недоступно: проверьте первый запуск по логу. На macOS при первой записи в crontab система может спросить разрешение для терминала.

## Обновление

```sh
uv tool upgrade dawg-replay
```

Скрипты, пресеты и история запусков сохраняются. Плагин Claude Code обновляется командой `/plugin marketplace update dawg-replay`.

## Где лежат данные

Скрипты, их версии, пресеты, история запусков и файлы результатов хранятся в каталоге данных:

| ОС | Каталог |
|---|---|
| macOS | `~/Library/Application Support/dawg-replay` |
| Windows | `C:\Users\<имя>\AppData\Local\dawg-replay` |
| Linux | `~/.local/share/dawg-replay` (или `$XDG_DATA_HOME/dawg-replay`) |

Точный путь покажет `dawg-replay config show`. Файлы результатов лежат в `runs/<номер запуска>/output/`. Другой каталог можно задать переменной окружения `DAWG_REPLAY_HOME`.

Ключ DAWG и секреты скриптов (например, токен таблицы) в каталог данных не попадают, они хранятся в системном хранилище паролей под именем `dawg-replay`.

## Удаление

Сначала снимите регулярные запуски, иначе задачи останутся в планировщике: `dawg-replay schedule list`, затем `dawg-replay schedule remove <id>` для каждого. Потом удалите приложение:

```sh
uv tool uninstall dawg-replay
```

Затем удалите каталог данных из таблицы выше, если история и скрипты больше не нужны. Ключ DAWG и секреты скриптов уберите из хранилища паролей: это записи с `dawg-replay` в имени в приложении «Связка ключей» (macOS), в Диспетчере учётных данных (Windows) или в менеджере паролей Linux, например Seahorse. Плагин Claude Code удаляется командой `/plugin uninstall dawg-replay-builder@dawg-replay`.

## Безопасность

Скрипт это обычная программа на Python. Она запускается на вашем компьютере с вашими правами и вашим ключом DAWG, песочницы нет. Добавляйте скрипты, которые собрал ваш агент или прислал человек, которому вы доверяете. Перед добавлением файла через интерфейс посмотрите его карточку: какие пакеты он поставит и что изменилось в коде.

Интерфейс слушает только этот компьютер (127.0.0.1) и открывается по ссылке с токеном, который действует, пока работает `dawg-replay ui`. Другие сайты, открытые в браузере, обратиться к интерфейсу не могут.
