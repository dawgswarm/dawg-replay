# the-internet-actions

Демо действий по таблице для приёмки M3 на учебном сайте https://the-internet.herokuapp.com.
Для каждой строки таблицы скрипт входит в кабинет (или берёт сохранённый вход), открывает
закрытую страницу и сверяет заголовок. На сайте ничего не меняется.

Что видно на демо:

- таблица `accounts.csv` из 5 строк, третья с неверным логином и паролем падает, остальные проходят;
- вход сохраняется между строками и запусками: страница скрипта, блок «Сохранённые входы»;
- вопрос посреди запуска: подтверждение перед началом и учебный код (верный ответ 1234);
- отчёт по строкам на экране запуска и «Перезапустить упавшие».

Таблица секретная (в ней пароли): в историю запусков она не попадает, в пресете хранится отдельным файлом, в событиях её
значения заменяются на `***`, поэтому строки в отчёте названы номерами.

## Запуск

    dawg-replay validate examples/the-internet-actions/script.py
    dawg-replay add examples/the-internet-actions/script.py
    dawg-replay run the-internet-actions --param accounts=@examples/the-internet-actions/accounts.csv --follow

`--follow` задаёт вопросы в терминале. В интерфейсе: загрузите `accounts.csv` в форму запуска,
вопросы появятся на экране запуска.

Пока kit 1.2 не опубликован на PyPI, приложению нужен локальный kit:

    dawg-replay config set dev_kit_source "$PWD/packages/dawg-replay-kit"
