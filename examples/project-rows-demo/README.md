# Демо: значения по стрелке и проход по строкам

Три скрипта-заглушки без браузера и сайта и проект из них. Минуты DAWG не тратятся, ключ DAWG не нужен.

| Скрипт | Что делает | Отдаёт |
|---|---|---|
| `demo-login` | «входит в кабинет» | выходные значения `token` (секретное) и `shop` |
| `demo-cities` | список городов | `cities.csv`: `Город`, `Активен` (Омск неактивен) |
| `demo-city-prices` | цены в одном городе, нужен токен от `demo-login` | `prices.csv`: `sku`, `price`, `shop` |

Проект `demo-rows.project.toml`:

- `login → prices`: токен и название магазина идут во входы `token` и `shop` (`{ value = ..., to = ... }`);
- `cities → prices`: колонка `Город` идёт во вход `city` по разу на каждую строку (`rows = "each"`),
  только активные города (`where`), по два запуска одновременно (`parallel = 2`), при падении строки
  остальные идут дальше (`on_error = "continue"`).

`demo-city-prices` один раз падает на городе из «Упасть на» (по умолчанию Казань): метка падения лежит
во временном каталоге системы, в `dawg-replay-demo-rows`. Повтор проходит.

## Как проверить

```sh
for f in examples/project-rows-demo/demo-*.py; do dawg-replay add "$f"; done
dawg-replay project add examples/project-rows-demo/demo-rows.project.toml

dawg-replay project run demo-rows --follow
```

Итог «частично»: у узла «Демо: цены в городе» строк 3 из 4, упала Казань. Каждая строка это обычный
запуск скрипта с пометкой шага и номера строки (`dawg-replay runs demo-city-prices`). Результат шага
это запуск-сборка: `prices.csv` всех городов с колонкой `Город` в начале.

```sh
dawg-replay project status <id запуска проекта>
dawg-replay project retry <id запуска проекта> --follow
```

Перезапуск повторяет только Казань, готовые города берутся из прошлого запуска. Итог «готово», строк 4 из 4.

Ещё попробовать:

- `limit = 2` у стрелки `cities → prices`: только первые два города;
- `on_error = "stop"`: после падения оставшиеся города не запускаются, шаг «упал»;
- `where = { column = "Город", op = "equals", value = "Париж" }` у той же стрелки: таких строк нет,
  шаг «пропущен» с причиной «нет строк»;
- убрать стрелку `cities → prices`: вход «Город» пуст, проект сохраняется, но не запускается
  (`dawg-replay project check demo-rows` показывает «не задан «Город»»).

Начать демо заново (Казань снова упадёт один раз): удалить каталог `dawg-replay-demo-rows` во временном
каталоге системы. Удалить демо: `dawg-replay project remove demo-rows` и `dawg-replay remove <скрипт>` для
каждого скрипта.
