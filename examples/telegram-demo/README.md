# telegram-demo

Демо для приёмки уведомлений в Telegram ([план](../../docs/acceptance/m5-telegram.md)). Браузер не
открывается, сайт не нужен, минуты DAWG не тратятся, ключ DAWG для запуска не нужен (без ключа
приложение предупреждает «ключ DAWG не задан», демо это не мешает).

Параметры:

| Параметр | Что делает |
|---|---|
| `outcome` | `ok` готово, `partial` частично (строки 2 и 4 из 5 упали), `failed` падение с объяснением, `crash` ошибка в коде без итога |
| `minutes` | сколько минут работать до вопроса и итога (дробное, например `0.5`) |
| `ask` | `none`, `confirm` (да или нет), `code` (секретный ответ), `choice` (город из трёх), `text` (ответ текстом) |
| `ask_minutes` | сколько ждать ответа; не дождался: итог «упал» с причиной «не дождались ответа» |
| `count` | сколько записей «собрано»; `0` при `ok` даёт тихую поломку «скрипт сообщил, что собрал 0 записей» |

Главный файл итога `result.csv` (строк столько, сколько `count`, но не больше 1000), ссылка в итоге
ведёт на описание ботов Telegram. Секретный ответ скрипт не печатает, в журнал пишет только его длину.

## Запуск

    dawg-replay add examples/telegram-demo/script.py
    dawg-replay run telegram-demo --set minutes=0.5 --set ask=confirm --follow
    dawg-replay run telegram-demo --set outcome=partial          # в фоне, без --follow
