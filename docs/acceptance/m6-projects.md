## Подготовка

1. Скрипты демо:

       for f in examples/pipeline-demo/demo-*.py examples/project-rows-demo/demo-*.py; do dawg-replay add "$f"; done

   На Windows (PowerShell): `Get-ChildItem examples\pipeline-demo\demo-*.py, examples\project-rows-demo\demo-*.py | ForEach-Object { dawg-replay add $_.FullName }`.
2. Встроенные узлы на месте: `dawg-replay list` показывает `std-filter-rows`, `std-if`, `std-merge-tables`,
   `std-select-columns` с пометкой `[встроенный]`.
3. Рабочая копия файла проекта, её будем править: `cp examples/pipeline-demo/demo-prices.project.toml prices.project.toml`.

Демо «упасть один раз» помнит падение файлом в `dawg-replay-demo-pipeline` и `dawg-replay-demo-rows` во временном
каталоге системы (`$TMPDIR` на macOS, `/tmp` на Linux, `%TEMP%` на Windows). Чтобы сценарий с падением повторить,
удалите эти каталоги.

  yes.csv; yes.csv → updated»);

### Ф2. Ошибки не дают сохранить

Файл `bad.project.toml`:

```toml
name = "demo-bad"
title = "С ошибками"

[[nodes]]
id = "a"
script = "demo-wb-prices"

[[nodes]]
id = "b"
script = "demo-report"

[[edges]]
from = "a"
to = "b"
map = [{ from = "prices.csv", column = "price", to = "updated" }]

[[edges]]
from = "b"
to = "a"
```

1. `dawg-replay project check bad.project.toml`, затем `dawg-replay project add bad.project.toml`.

Ожидается: код выхода 1, обе ошибки названы:
«стрелка a → b: вход `updated` типа table: колонка идёт во вход-значение; таблица целиком: { from = "prices.csv",
to = "updated" } без column» и «круг: a → b → a. Циклов в проекте быть не может; повторы делайте внутри
узла-скрипта». Проекта `demo-bad` в `dawg-replay project list` нет.

Отметить: [ ] ошибки понятны, [ ] не сохранилось.
