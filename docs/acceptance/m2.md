# Приёмка M2: скилл dawg-replay-builder

Спека, раздел 9: агент в чистой сессии Claude Code и Codex по одной фразе клиента создаёт рабочие скрипты для трёх сайтов: маркетплейс, сайт спортивной статистики, Avito. Скрипт рабочий, если три запуска подряд с разными параметрами дают правильные данные (выборка сверяется руками) и проходят проверки M1. Отдельно проверяется починка намеренно сломанного скрипта.

Документ готовит всё для проведения. Как проводить сессии агентов (кто, когда, на каком тарифе), решает пользователь.

## 0. Перед началом

- [ ] В `main` есть `skill/skills/dawg-replay-builder/template.py` и `exploration.md` (отдельный тикет). Без них скилл ссылается на пустоту.
- [ ] Доступность сайтов из браузера DAWG проверена в день приёмки (раздел 3). Состояние на 14.11.2026: Ozon и championat.com открываются; Avito и Wildberries дают `net::ERR_TUNNEL_CONNECTION_FAILED` (Avito с `geo=moskva`, `geo=kazan` и без geo); запасной сайт объявлений Дром открывается.
- [ ] Записан остаток минут ключа до приёмки: `dawg-replay` UI, экран Настройки, или `GET /api/v1/usage`.
- [ ] Записан список живых сессий ключа до приёмки (`browser_list_sessions`, поле `account_sessions`): чужие сессии потом не считаются и не трогаются.

## 1. Установка до публикации на PyPI

Проверено 14.11.2026 на чистом `DAWG_REPLAY_HOME`, отдельном каталоге инструментов uv и отдельном конфиге Claude Code (`CLAUDE_CONFIG_DIR`): установка, `--version --json`, регистрация примера Ozon, живой запуск `ok`, `dawg-replay ui` отдаёт страницы, плагин ставится из локального маркетплейса и включается. Codex на машине проверки не было: шаги для него по документации Codex (раздел 1.4).

`<repo>` ниже это абсолютный путь к клону `dawg_replay` на свежей `main`.

### 1.1 Приложение

```
uv tool install --python 3.10 <repo>/packages/dawg-replay --with <repo>/packages/dawg-replay-kit
dawg-replay --version --json                       # "contract_versions": ["1.1"]
dawg-replay config set-key                         # ключ DAWG в системное хранилище паролей
dawg-replay config set dev_kit_source "<repo>/packages/dawg-replay-kit"
```

`dev_kit_source` нужна, пока kit не на PyPI: приложение собирает kit из репозитория и подкладывает его в `uv run` скрипта (`dawg_replay.devkit`). Чистый каталог данных для приёмки: `export DAWG_REPLAY_HOME=~/dawg-replay-m2` в той же оболочке, где потом запускается агент (иначе каталог по умолчанию платформы).

Автономный запуск скрипта без приложения (проверка критерия 10.2):

```
eval "$(dawg-replay dev kit-env | head -1)"
uv run --reinstall-package dawg-replay-kit script.py --help
```

### 1.2 Плагин Claude Code из `skill/`

```
claude plugin marketplace add <repo>/skill
claude plugin install dawg-replay-builder@dawg-replay
```

Затем в сессии `/plugin configure dawg-replay-builder@dawg-replay`, ввести ключ DAWG. Проверка в сессии: `/plugin` без ошибок, `/mcp` показывает сервер `dawg` плагина. Если `dawg` уже подключён вручную (`claude mcp add dawg ...`), оставить один из двух серверов (`skill/README.md`).

Чистая сессия: новый пустой каталог вне репозитория `dawg_replay` (иначе агент увидит `examples/` и готовые скрипты), `claude` из него.

### 1.3 После приёмки

```
claude plugin uninstall dawg-replay-builder@dawg-replay
claude plugin marketplace remove dawg-replay
uv tool uninstall dawg-replay
```

### 1.4 Codex

```
mkdir -p ~/.agents/skills
cp -R <repo>/skill/skills/dawg-replay-builder ~/.agents/skills/
```

В `~/.codex/config.toml`:

```toml
[mcp_servers.dawg]
command = "uvx"
args = ["--with", "mcp<2", "dawg-mcp"]
env_vars = ["DAWG_API_KEY"]
```

`export DAWG_API_KEY=...` в оболочке, из которой запускается `codex`; там же `DAWG_REPLAY_HOME`. Перезапустить Codex. Проверка: `/skills` показывает `dawg-replay-builder`, `/mcp` показывает `dawg`. Сессия из пустого каталога вне репозитория.

## 2. Фразы клиента

Каждая фраза в новой сессии, дословно, одним сообщением. На уточняющие вопросы агента отвечать коротко, как клиент: без подсказок про API, селекторы и устройство приложения.

### 2.1 Маркетплейс: Ozon

> Мне нужно раз в неделю выгружать с Озона товары по поисковому запросу: название, цена, цена без скидки, рейтинг, число отзывов и ссылка. Запросы я буду менять сам, иногда нужен диапазон цены и сортировка по цене. Результат в Excel.

Если на день приёмки Wildberries снова доступен, его можно взять вместо Ozon той же фразой с заменой «Озона» на «Вайлдберриз».

Ответы на вероятные вопросы: страниц обычно 2-3; «Excel» значит файл, который открывается в Excel (CSV подходит).

Отличие от эталона `examples/ozon-search-cards`: фильтр по диапазону цены, его в эталоне нет. Совпадение кода с эталоном считается копированием, если агенту не показывали `examples/`.

### 2.2 Спортивная статистика: championat.com

> Хочу собирать турнирные таблицы футбольных чемпионатов с сайта championat.com: место, команда, игры, победы, ничьи, поражения, забитые и пропущенные мячи, очки. Сейчас нужна РПЛ, потом буду смотреть и другие лиги.

Проверено через dawg-mcp: `https://www.championat.com/football/_russiapl/tournament/7096/table/` открывается без входа и капчи, таблица РПЛ 2026-2027 есть в HTML страницы (`table tr`, 16 команд), на странице есть ссылки на таблицы других турниров (`/tournament/<id>/table/`). Правильный скрипт принимает лигу или турнир параметром, а не зашивает 7096.

### 2.3 Объявления: Avito, запасной Дром

> Собирай с Авито объявления о продаже велосипедов в Казани дешевле 30 тысяч: название, цена, ссылка и когда опубликовано. Город и цену иногда буду менять.

Если в день приёмки Avito из браузера DAWG не открывается (раздел 3), вместо него:

> Собирай с Дрома объявления о продаже машин в Казани дешевле миллиона: марка и модель, год, цена, пробег, ссылка. Город и цену иногда буду менять.

Проверено через dawg-mcp: `https://auto.drom.ru/kazan/do-1000000/all/` открывается без входа и капчи, в выдаче 20 объявлений на странице, пагинация ссылками `page2/`, `page3/`.

### 2.4 Сценарий C: «скрипт сломался»

Подготовка (в том же `DAWG_REPLAY_HOME`, до сессии агента):

```
dawg-replay add <repo>/examples/ozon-search-cards/script.py           # рабочая версия N (эталон)
dawg-replay add <repo>/docs/acceptance/m2/ozon-search-cards-broken.py  # сломанная версия N+1, становится текущей
dawg-replay run ozon-search-cards --set "query=мяч футбольный" --set max_pages=3 --follow
```

Последняя команда даёт `partial`: «страница 2 выдачи не загрузилась за 45 с прокрутки», собрана одна страница. Поломка: в `is_page_response` путь внутреннего API выдачи заменён на несуществующий (`/api/entrypoint-api.bx/page/json/v3` вместо `.../v2`), поэтому ответы со следующими страницами не распознаются. Других отличий от `examples/ozon-search-cards/script.py` нет (`diff` покажет две строки: `version` и путь). Копию собирает `python docs/acceptance/m2/make_broken.py` из текущего эталона; тест `test_acceptance_m2.py` падает, если эталон изменился, а копию не пересобрали. Проверено 14.11.2026: сломанная версия даёт `partial` на странице 2, эталон с теми же параметрами `ok`, 3 страницы.

Фраза в новой сессии:

> Скрипт для Озона сломался: вчера поставил три страницы, а он собрал только первую. Почини, пожалуйста.

Ожидается: агент находит запуск через `dawg-replay runs ozon-search-cards --json` и `logs --events`, проходит прокрутку выдачи через dawg-mcp, видит, что страница запрашивает `.../page/json/v2`, правит тот же файл (текущую версию), поднимает `version` до N+2, проверяет и делает `add`. Слайдер-капча Ozon на отдельных выходах бывает и без поломки: если агент получил её, он должен сказать об этом и повторить запуск, а не обходить капчу.

## 3. Проверка доступности сайта в день приёмки

Через dawg-mcp в любой сессии с подключённым `dawg`: `browser_provision`, `browser_navigate` на адрес из раздела 2, смотреть заголовок и наличие данных, `browser_release`. Или прогнать эталон Ozon: `dawg-replay run ozon-search-cards --set max_pages=1 --follow`.

Признаки, что сайт сейчас не годится: `ERR_TUNNEL_CONNECTION_FAILED` (прокси платформы не пускает на домен), капча на первом же заходе, страница входа вместо выдачи.
