# Приёмка M3: действия на сайтах по таблице

Спека `docs/specs/2026-11-15-m3-actions.md`, раздел 6: демо-скрипт действий на учебном сайте с формой входа, таблица из 5 строк, одна заведомо падает, вход сохраняется между запусками, вопрос с кодом, перезапуск упавших. Прогон в UI на macOS, CI на трёх ОС.

Демо: `examples/the-internet-actions` (сайт https://the-internet.herokuapp.com, таблица `accounts.csv`: 4 строки с рабочим аккаунтом сайта, третья с неверным логином).

## Как провести

```
dawg-replay config set dev_kit_source "<repo>/packages/dawg-replay-kit"   # пока kit 1.2 не на PyPI
dawg-replay add examples/the-internet-actions/script.py
dawg-replay ui
```

1. Страница скрипта, «Запустить»: загрузить `accounts.csv` в поле «Аккаунты». Видно имя файла и «5 строк», содержимое не показывается: таблица секретная.
2. «Запустить». На экране запуска вопрос «Пройти по 5 строкам таблицы…»: «Да». Затем учебный код: `1234`.
3. Итог «частично»: в блоке «Строки» 4 сделаны, строка 4 упала с «Your username is invalid!»; строки 3, 5, 6 открыли кабинет по сохранённому входу.
4. «Перезапустить упавшие»: новый запуск только со строкой 4, снова вопросы, итог «ошибка» (пароль в таблице по-прежнему неверный).
5. Страница скрипта, «Сохранённые входы»: только `tomsmith`. Неудачный вход скрипт стирает (`b.forget_login()`).

## Прогон 15.11.2026

macOS, Chrome без окна (Playwright), отдельный каталог данных, ключ DAWG разработки, локальный kit.

| Шаг | Результат |
|---|---|
| Загрузка таблицы | `accounts.csv`, 5 строк, превью скрыто (секретная) |
| Вопросы | на подтверждение и учебный код ответил в UI; в событиях ответа на код нет (`ask_closed` без `answer`) |
| Запуск 1 | `partial`, «4 из 5»: строка 2 вход выполнен, строки 3, 5, 6 сохранённый вход, строка 4 `failed` |
| Перезапуск упавших | новый запуск с одной строкой 4, `failed` |
| Сохранённый вход | после исправления в шаблоне неудачный вход не остаётся (`dawg-replay logins list`: только `tomsmith`) |
| Секреты | пароли не найдены в каталоге запусков, БД и логах; только в загрузке таблицы (`uploads/`, 0600, сутки) |
| Браузеры DAWG | открыто 8, закрыто 8 за все прогоны; предупреждений «возможно, остался браузер» нет; ≈ 0,7 мин |
