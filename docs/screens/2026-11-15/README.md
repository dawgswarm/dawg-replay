# Экраны dev на 2026-11-15

Что появилось за ночь: регулярные запуски (dr-47), «Починить с агентом» и тихая поломка (dr-49), примерные минуты браузеров (dr-50), очередь плановых запусков (dr-52), шапка запуска и порядок блоков на странице скрипта (dr-56), тихая поломка во всех списках (dr-55). Скриншоты сняты на демо-данных в headless Chrome.

## Запустить демо самому

Из корня репозитория, одной командой:

```sh
uv run --all-packages python testing/demo_home.py
```

Команда создаёт временный каталог данных, заполняет его и печатает ссылку на интерфейс. Остановить: Ctrl+C. Ключ DAWG и сеть не нужны. Настоящий crontab и хранилище паролей не трогаются: у демо свой фейковый crontab и пустой keyring.

В демо три скрипта (Ozon, Wildberries, футбол), четыре пресета, три расписания и неделя истории запусков. Лимит одновременных запусков 1: футбол идёт, плановый Wildberries ждёт свободного слота, ночной плановый Wildberries пропущен (не дождался слота). Идущий и ждущий запуски держит фоновый процесс демо, после Ctrl+C он завершается. Прошлый визит в интерфейс записан вчерашним вечером, поэтому на главной виден блок «С прошлого визита».

Переснять скриншоты (нужен установленный Google Chrome):

```sh
uv run --all-packages python testing/demo_screens.py docs/screens/2026-11-15
```

## Что на скриншотах

Каждый экран снят в двух темах: `-light` светлая, `-dark` тёмная.
