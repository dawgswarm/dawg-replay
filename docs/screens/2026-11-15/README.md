# Экраны dev на 2026-11-15

Что появилось за ночь: регулярные запуски (dr-47), «Починить с агентом» и тихая поломка (dr-49), примерные минуты браузеров (dr-50). Скриншоты сняты на демо-данных в headless Chrome.

## Запустить демо самому

Из корня репозитория, одной командой:

```sh
uv run --all-packages python testing/demo_home.py
```

Команда создаёт временный каталог данных, заполняет его и печатает ссылку на интерфейс. Остановить: Ctrl+C. Ключ DAWG и сеть не нужны. Настоящий crontab и хранилище паролей не трогаются: у демо свой фейковый crontab и пустой keyring.

В демо три скрипта (Ozon, Wildberries, футбол), четыре пресета, три расписания и неделя истории запусков. Прошлый визит в интерфейс записан вчерашним вечером, поэтому на главной виден блок «С прошлого визита».

Переснять скриншоты (нужен установленный Google Chrome):

```sh
uv run --all-packages python testing/demo_screens.py docs/screens/2026-11-15
```

## Что на скриншотах

Каждый экран снят в двух темах: `-light` светлая, `-dark` тёмная.

| Файл | Экран | На что смотреть |
|---|---|---|
| `01-home-*` | Главная | «С прошлого визита»: ночное падение WB и тихая поломка Ozon с кнопками «Починить с агентом». «По расписанию»: ближайшие плановые запуски. «Минуты и браузеры»: примерный расход за неделю. В «Последних запусках» плановые запуски помечены «по расписанию» |
| `02-library-*` | Скрипты | Карточки трёх скриптов с последним запуском и пресетами |
| `03-script-schedules-minutes-*` | Страница скрипта Ozon | История запусков, минуты за 7 дней в шапке блока «Запуски», блок «Регулярный запуск» с расписанием и формой |
| `04-run-failed-repair-*` | Упавший плановый запуск WB | Панель «Починить с агентом» раскрыта: текст для агента, кнопка «Скопировать». Токен из адреса в stderr скрыт |

| `06-history-*` | История WB | Плановые запуски каждые 6 часов, последний упал |
| `07-settings-*` | Настройки | Ключ не задан (демо без ключа) |
